# 阅读指南：组合优化与学习控制分别进阶

核验截止：2026-10-02。初学者先理解两条研究线的差别，再选一条深入。近似算法、在线学习和控制理论共享部分数学工具，但评价对象与证明条件不同。[领域综述](review.md)提供公式解释，[代表与前沿研究](representative-research.md)提供选定来源。本指南不是完整课程或系统文献综述。

## 共同准备：先解释符号

补集合、图、函数、概率期望、梯度、凸集与大O。用三个覆盖集合检查收益递减，写出两个颜色配额加预算的可行方案，再用三天损失表计算静态遗憾。每个符号都应能用一句话解释。

阶段目标是知道目标值更大或更小是否更好，分清最大化两种近似比惯例，说明期望可行与一次运行严格可行的区别。

## A线：近似与组合优化

先读R097公平k集合的第1–3页，然后看一般图舍入与最大度受限情形。画左侧元素、右侧集合的二部图，手动选择k个集合，计算元素最大负担。把困难情形与可精确处理的特殊结构分开记录。

再读R098公平次模背包的定义、主定理条件和舍入难点。手算四项目、两颜色例子：分别以概率1/2选项目，期望每组一个并不保证实际每组一个。检查颜色数为常数、单调性与约束放松究竟出现在什么定理中。

接着读R100加权Nash福利的第1–3页、配置LP与大小物品舍入。先算两人效用(9,1)与(5,5)的福利，不急于追完整常数233。把一条引理改写为“假设、要证明、关键工具”三行，再读R102 v3摘要与主定理，避免把新论文3.56的比率归给较早R100。

调度方向可接R103第3页摘要：最少校准次数与固定预算最大完成权重是不同目标，T=2和T≥3有不同复杂度。其正式卷期与在线发表日期分开记录，摘要依据不能冒充完整证明审阅。

每篇完成一页证明卡，含估值访问模型、运行时间、随机性、约束违反和失败概率。短版省略证明时标注长版待读。阶段目标是说明松弛值如何界住最优、舍入为什么丢失质量，以及某个LP的整数间隙为何不自动是所有算法的下界。

## B线：在线学习、博弈与控制

先读Zinkevich原文定义与投影梯度，再读Hazan教材相关章节。用一维区间[0,1]练习投影，比较固定最佳和每天最佳两个参照。解释平方根遗憾界时，同时写有界梯度、集合直径与反馈条件；非凸模型不能直接照搬凸优化界。

再读DQN原始研究的状态、动作、奖励和价值关系。写两状态两动作的转移表，解释为何同样的即时奖励仍可能导致不同动作选择。随后读[SCORER论文卡](../papers/P146.md)所指2026-01-28 v3，记录Q领导者与编码器跟随者的目标。

SCORER v3第6页算法在同一更新时刻先更新编码器，再更新Q；快慢由衰减学习率比实现，不要仅凭摘要理解为不同更新次数。第4页式(2)批内方差采用分母N：误差[1,3]的均方为5、批内方差为1；[2,2]的均方为4、方差为0。方差小不能替代价值偏差小。早期v1角色安排不同，整套公式应使用同一版本。

继续阅读[分布式不可分在线凸优化](../papers/P145.md)时，检查节点维护哪些联合决策信念，以及通信假设和开销。作者版v2正文已有一般步长指数c的界，c=1/2是平方根阶特例。读[TTC-X](../papers/P153.md)可比较预测辅助的有限动作在线控制与连续凸优化；完整PiCOL还包含其他相机动作的条件化和探索，简化指数权重公式不等于完整实现。

阶段目标是分清均衡存在、迭代收敛、控制稳定与任务回报提升这四类结论；LQR零阶元优化的全局保证也需先核任务及稳定性条件。

## 进阶：提出一个有边界的问题

A线可增加一种配额或预算约束，先检查可行性，再定位原舍入证明失效的步骤。B线可改变反馈延迟或学习率时间尺度，先定义环境、比较策略和交互预算，再设计消融。

两线均产出已读事实、研究假设、未解决疑问各一页。实践结果应包含相同计算或交互预算下的比较；未运行的实验保留为计划，手算例子保留为解释。引用前核对正式版本和最新修订，核验截止之后的进展需要另行检查。
